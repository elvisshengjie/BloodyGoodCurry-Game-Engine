Project Guide
==============

1. Install CMake
----------------
CMake is required to generate Visual Studio solutions.

- Download the latest version here:
  https://cmake.org/download/

- During installation:
  - Choose "Add CMake to system PATH".
  - Verify installation:
    ```powershell
    cmake --version
    ```

2. Regenerating the Visual Studio 2022 Solution
-----------------------------------------------
1. Open **Developer PowerShell for VS 2022** (or normal PowerShell).
2. Navigate to the project root folder (where `CMakeLists.txt` is located):
   ```powershell
   cd path\to\project
   ```
3. Create a `build` directory (if not already present):
   ```powershell
   mkdir build
   cd build
   ```
4. Run CMake to generate a Visual Studio 2022 solution:
   ```powershell
   cmake -G "Visual Studio 17 2022" ..
   ```
   - `..` tells CMake to look at the parent folder for `CMakeLists.txt`.
   - This will generate `giraphics.sln` inside the `build` folder.

5. Open the solution in Visual Studio:
   ```powershell
   start giraphics..sln
   ```

Important!

Use the clean.bat file then run the run.bat file for editor Mode (Offline)
Use the clean.bat file run run_game.bat for non editor mode in release mode (Offline)

3. PROJECT SETTINGS (DEBUG VS RELEASE)
--------------------------------------
Once the solution is open in Visual Studio, you can toggle between configurations using the dropdown menu in the top toolbar.

* **Debug Mode:** - Use this for development.
  - Features: Unoptimized code, full debug symbols, and enables console logging/assertions.
  - Performance: Slower.
  - able to use F9 for Crash logging
  -F1 to show performance panel

* **Release Mode:**
  - Use this for final deployment or performance testing.
  - Features: Fully optimized code. Debug logs may be disabled.
  - Performance: Runs at maximum speed.
    -F1 to show performance panel

Editor Mode (Offline)

-Run: clean.bat then run.bat

Game Mode (Offline / no editor)

-Run: clean.bat then run_game.bat

ShortCut
F10: Toggle editor panels (show/hide editor UI).

F11: Toggle fullscreen. (Works regardless of editor).

Extra editor controls when editor UI is visible:

T / R / S switch gizmo modes (Translate/Rotate/Scale).

Delete removes selected object (editor-only flow).





That's it — the project is ready to build and run in Visual Studio 2022.

4. WEB BUILD AND RUN (BROWSER)
------------------------------
Use this when testing the Emscripten/WebGL build.

Install first (one-time setup):
- Visual Studio 2022 with "Desktop development with C++" workload
- CMake (add to PATH)
- Ninja (add to PATH)
- Python 3 (add to PATH)
- EMSDK (Emscripten SDK)

Quick checks:
```powershell
cmake --version
ninja --version
python --version
em++ --version
```

Recommended install commands (Windows + winget):
```powershell
winget install Kitware.CMake
winget install Ninja-build.Ninja
winget install Python.Python.3.12
```

EMSDK setup example:
```powershell
git clone https://github.com/emscripten-core/emsdk.git $env:USERPROFILE\emsdk
cd $env:USERPROFILE\emsdk
.\emsdk install latest
.\emsdk activate latest
.\emsdk_env.bat
```

Note:
- `build_web_html.bat` auto-loads `%USERPROFILE%\emsdk\emsdk_env.bat` if `EMSDK` is not set.

1. Build web output (recommended split-file release):
   ```powershell
   build_web_html.bat release-split reconfigure
   ```

2. Start local web server from project root:
   ```powershell
   python -m http.server 8000 -d build\web-release-split\Sandbox
   ```

3. Open the game:
   ```text
   http://localhost:8000/BloodyGoodCurry.html?v=1
   ```

4. After each rebuild:
   - Increase the query string value (`v=2`, `v=3`, etc.)
   - Hard refresh browser: `Ctrl+Shift+R`

Web notes:
- Do not open `BloodyGoodCurry.html` directly from file explorer.
- Always host with `http.server` (or equivalent local server).
- Web version currently uses audio stubs, so no FMOD sound output in browser.
